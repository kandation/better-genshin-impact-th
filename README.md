## ฟีเจอร์
* **งานแบบเรียลไทม์**
    * **[เก็บของอัตโนมัติ](https://www.bettergi.com/feats/timer/pick.html):** กด <kbd>F</kbd> เมื่อมีจุดโต้ตอบ/เก็บของ รองรับ whitelist/blacklist
    * **[ข้ามบทสนทนาอัตโนมัติ](https://www.bettergi.com/feats/timer/skip.html):** คลิกข้ามบท, เลือกตัวเลือก, ส่งไอเทม, ปิดหน้าต่างป๊อปอัป ฯลฯ
        * รับรางวัล **เควสประจำวัน** และ **[ส่งออกเดินทางใหม่](https://www.bettergi.com/feats/timer/skip.html#%E8%87%AA%E5%8A%A8%E9%87%8D%E6%96%B0%E6%B4%BE%E9%81%A3)** อัตโนมัติเมื่อคุยกับ Katherine
    * **[เชิญชวนอัตโนมัติ](https://www.bettergi.com/feats/timer/skip.html#%E8%87%AA%E5%8A%A8%E9%82%80%E7%BA%A6):** เลือกตัวเลือกเชิญชวนอัตโนมัติ (ต้องเปิดข้ามบทก่อน)
    * **[เทเลพอร์ตเร็ว](https://www.bettergi.com/feats/timer/tp.html):** คลิกจุดเทเลพอร์ตบนแผนที่และเทเลพอร์ตอัตโนมัติ
    * **[ตกปลาครึ่งอัตโนมัติ](https://www.bettergi.com/feats/timer/fish.html):** โยนเบ็ด, ดึงเบ็ดเมื่อปลากิน และตกปลาด้วย AI

* **งานอิสระ**
    * **[Genius Invokation TCG อัตโนมัติ](https://www.bettergi.com/feats/task/tcg.html):** เคลียร์ PvE เช่น เชิญตัวละครและดวลรายสัปดาห์
    * **[ตัดไม้อัตโนมัติ](https://www.bettergi.com/feats/task/felling.html):** ใช้ <kbd>Z</kbd> (Boon of the Elder Tree) และ relog เพื่อฟาร์มไม้
    * **[ดันเจี้ยนอัตโนมัติ](https://www.bettergi.com/feats/task/domain.html):** ฟาร์มดันเจี้ยนเต็มรอบ รวมต่อสู้และรับรางวัล
    * **[Stygian Onslaught อัตโนมัติ](https://www.bettergi.com/feats/task/stygian.html):** เทเลพอร์ตและเคลียร์ Stygian Onslaught (ส่วนใหญ่ด่าน 3 สำหรับฟาร์ม artifact)
    * **[ตกปลาเต็มอัตโนมัติ](https://www.bettergi.com/feats/task/fish.html):** ตกปลาที่จุดที่กำหนด รวมสลับกลางวัน/กลางคืน
    * **[Ley Line Outcrop อัตโนมัติ](https://www.bettergi.com/feats/task/leyline.html):** ฟาร์ม Ley Line ต่อเนื่องที่จุดส่วนใหญ่
    * **[มินิเกมจังหวะอัตโนมัติ](https://www.bettergi.com/feats/task/music.html):** เคลียร์อัลบั้ม Repertoire of Myriad Melodies สำหรับ achievement
    * **[ทำอาหารอัตโนมัติ](https://www.bettergi.com/feats/task/cook.html):** ทำอาหารในช่วง perfect อัตโนมัติ
    * **[ย่อย Artifact อัตโนมัติ](https://www.bettergi.com/feats/task/artifactSalvage.html):** รองรับ **Quick Salvage** และ **ย่อยตามกฎ**

* **อัตโนมัติเต็มรูปแบบ**
    * **[One-Click Daily (一条龙)](https://github.com/babalae/better-genshin-impact/issues/846):** เคลียร์งานประจำวันและรับรางวัล
    * **[เก็บของ/ขุดแร่/ฟาร์มอัตโนมัติ](https://www.bettergi.com/feats/autos/pathing.html):** ตรวจจับจาก minimap
    * **[บันทึกมาโครคีย์บอร์ด/เมาส์](https://www.bettergi.com/feats/autos/kmscript.html):** บันทึกและเล่นซ้ำการกดปุ่ม (ใช้กับ scheduler ได้)

* **ช่วยเหลือการควบคุม**
    * **[Neuvillette หมุนกล้อง](https://www.bettergi.com/feats/macro/other.html#%E9%82%A3%E7%BB%B4%E8%8E%B1%E7%89%B9-%E8%BD%AC%E5%9C%88%E5%9C%88):** กดค้างเพื่อหมุนกล้องแนวนอน (ใช้กับ Nahida ได้)
    * **[เสริม Artifact เร็ว](https://www.bettergi.com/feats/macro/other.html#%E5%9C%A3%E9%81%97%E7%89%A9%E4%B8%80%E9%94%AE%E5%BC%BA%E5%8C%96):** ข้ามแอนิเมชันด้วยการสลับแท็บ
    * **[ซื้อร้านค้าเร็ว](https://www.bettergi.com/feats/macro/other.html#%E4%B8%80%E9%94%AE%E8%B4%AD%E4%B9%B0):** ซื้อจำนวนเต็มในร้านทันที

## วิธีใช้งาน
**ความต้องการของระบบ:**
- Windows 10/11 (64-bit)
- [.NET 8 Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (จะแจ้งให้ติดตั้งหากยังไม่มี)

**⚠️ หมายเหตุ:**
1. รีสตาร์ทแอปหลังเปลี่ยนขนาดหน้าต่าง/ความละเอียด/จอ
2. ปิดฟิลเตอร์ภาพทั้งหมด (HDR/NVIDIA Filters) ความสว่างเกมค่าเริ่มต้น
3. รองรับเฉพาะความละเอียด `16:9` (แนะนำ `1920x1080` แบบหน้าต่าง)
4. **แอนตี้ไวรัสอาจบล็อกการจำลองอินพุต — เพิ่มใน whitelist**

เปิดแอป → เลือกวิธีจับภาพหน้า "Launch" → กด "Start"

คู่มือ: [Quick Start](https://www.bettergi.com/quickstart.html) | เอกสาร: [Documentation](https://www.bettergi.com/doc.html)

## คำถามที่พบบ่อย
* **ทำไมต้องรันด้วยสิทธิ์ admin?**
    - เกมรันด้วยสิทธิ์ admin การจำลองคลิกต้องใช้สิทธิ์เดียวกัน
* **เสี่ยงแบนหรือไม่?**
    - **ไม่แก้ไขไฟล์เกมหรืออ่าน memory** ใช้แค่การมองเห็นและจำลองอินพุต แต่ ToS ของ miHoYo ห้ามเครื่องมือบุคคลที่สาม — ใช้ด้วยความระมัดระวัง
* [FAQ เพิ่มเติม...](https://www.bettergi.com/faq.html)
